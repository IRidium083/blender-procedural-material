# Clear-finish scratch mask

`clear_finish_scratches.png` was generated with the built-in image_gen tool.
It is an artistic grayscale coverage mask, used as Non-Color data, not measured
surface height. It drives coat roughness and optional shallow coat-normal relief.
The image is packed into saved wood and FRP scenes. Exact tile-edge continuity
is not guaranteed; tile size changes scratch length and width together.

No surface photograph, no material color, no reflections, no shadows, no lighting, no gradients or vignette, no text, no border.
