# Machining microdetail

`machining_height.png` was generated for this project using the built-in
image_gen tool. It is synthetic detail, not measured surface data. Used as
Non-Color input for subtle base-color, anisotropy, and roughness variation.
Originally generated as height detail; the current shader does not use it for bump.
Exact tile-border continuity is not guaranteed.

Generation prompt:

Create a seamless tileable square grayscale height texture for a Blender machined metal shader. Flat orthographic data map, full frame, fine dense parallel vertical milling striations, subtle irregular spacing and interrupted micro tool chatter along the striations. Medium gray average, restrained grayscale contrast. No lighting, no reflections, no gradients, no shadows, no perspective, no objects, no text, no border. Equal uniform detail across the entire tile; seamless opposite edges. This is a technical surface micro-height map, not a photograph of a metal object.
